# Aoxiang Bi Portfolio

Personal portfolio highlighting NBA product work, AI-assisted sports tooling, and sports science — plain HTML, CSS, and light JavaScript.

## Pages

- `index.html` — About, focus areas, skills
- `experience.html` — Hupu NBA ops, MOTION lab, education; links to the live NBA Data Center
- `projects.html` — Star House, NBA Data Center, sports science site, HRV, JumPro
- `nba-data-center.html` — Interactive NBA multi-tool data hub (Hupu deliverable)

## Getting Started

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
